## Executive summary

This release adds the **China Export / in-transit shipment** workflow, strengthens **delivery costing**, improves **client payment handling**, introduces **admin order approval**, adds **delivery priority** on order lines, and polishes the **order form** and **China office** user experience.

---

## 1. Delivery module

- **Dedicated “New Delivery” page** (full page, same pattern as Orders and Warehouse Receive).
- **Per-line shipping on delivery:**
  - Weight (kg) per product line
  - Ship. rate / kg (prefilled from Warehouse Receive history)
  - Line shipping = weight × rate
- **Live totals:** total weight and shipping bill on the form.
- **Delivery cost visibility** in order details, client ledger, and related summaries.
- **Delivery view** shows per-line weight, rate, and shipping share.

---

## 2. Payments & client billing

- **Client-level payment pooling** — payments are recorded against the client, not forced to one order.
- **FIFO allocation** — received money is applied **oldest order first** (order bill, then delivery bill).
- **Payments UI updated** to explain pooled payments and optional order reference (notes only).
- **Client ledger** shows clearer order-wise bill / paid / due breakdown.
- **Payment form** shows client balance context when recording payments.

---

## 3. Order approval workflow (admin acceptance)

- New system status: **Awaiting acceptance** (blocks workflow until approved).
- New **“Blocks workflow”** flag on Order Statuses for custom blocking statuses.
- New permission: **`crm_orders_accept`** — Accept orders (approve for processing).
- **Accept order** action in order view for admins/managers.
- Until accepted, orders are **blocked** for:
  - Delivery
  - Billing allocation
  - Export shipments
- **All new orders** now start as **Awaiting acceptance** (including when created by admin).
- Dashboard shows **Awaiting acceptance** count.
- Order list highlights blocked orders; order view shows a warning notice.

## 5. China Export module (new major feature)

Tracks what the **China office** ships before goods arrive in Bangladesh.

### Database (v0.9.7)

- `crm_export_shipments` — shipment header (company, order, ship date, status, weight, notes).
- `crm_export_shipment_items` — partial quantities per order line.

### Functionality

- New sidebar module (default name: **China Export**), placed between **Orders** and **Warehouse / Receive**.
- **List** — search, filters, shipment details, void support.
- **Record export shipment** form:
  - **Order** first (searchable picker, not a long dropdown)
  - **Ship date**
  - **Export company** (highlighted field)
  - **Notes**
  - Partial ship quantities per line (e.g. 4 of 10)
  - Tracks **already shipped**, **to export**, optional weight per line
- **In-transit** status until received in Warehouse.
- **Order integration** — Exported / To export columns; link to record export from order view.
- **Delivery priority** indicators on export lines and in shipment detail popup.

### China Office user role

- New role: **CRM China Office** (`crm_china_office`).
- Access limited to the **export shipments** module.
- Login redirects directly to that module.

### Admin settings

- **Configurable menu label** under CRM Settings → General (e.g. rename to “China Operations”).

### Approval gate on export

- Unapproved orders appear in search with **status badge** and **“Admin approval required”** message.
- They are **visible but not selectable** for export.
- Server-side validation blocks export until admin accepts the order.

### UI polish

- Form layout: Order + Ship date on one row; Export company + Notes on second row.
- Shipment **view popup** fixed (layout, status badge, void button styling, priority lights).
